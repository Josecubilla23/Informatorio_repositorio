 Juego de Adivinanza

Un juego simple hecho en Python con Tkinter.  
El objetivo es adivinar un número secreto entre 1 y 100.

El programa te indica si el número es más grande o más chico,  
muestra tus intentos y guarda un historial de partidas.

---

## 🚀 Cómo ejecutarlo
1. Tener **Python 3** instalado.
2. Descargar este proyecto o clonarlo.
3. Abrir una terminal en la carpeta y ejecutar:

bash
python adivinanza_numero.py
